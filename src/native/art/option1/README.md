# Artwork option 1

`original-art.tar` preserves the artwork source from commit `9527b38`, before the sprite conversion. It contains the world, interiors, cave, opening, item icons and interior layout source.

The original drawing routines remain available in the game. Settings → Artwork → Option 1 selects them for comparison; Option 2 selects the modular PNG sprites. New gameplay and geography apply to both options.
